
## 📊 Features of the Project

- ✅ Load and inspect raw solar datasets
- ✅ Clean and preprocess the data (handling missing values, formatting)
- ✅ Generate descriptive statistics
- ✅ Create meaningful visualizations:
  - Time series plots of solar generation
  - Correlation heatmaps
  - Histograms and boxplots
- ✅ Detect trends and outliers in solar output
- ✅ Identify peak solar production periods
- ✅ Summarize findings for further modeling and decision-making

## 🧪 Technologies Used

This project uses the following Python libraries:

- `pandas` – data manipulation
- `numpy` – numerical operations
- `matplotlib` – data visualization
- `seaborn` – enhanced statistical plots
- `jupyter` – interactive coding environment

All dependencies are listed in `requirements.txt` for easy installation.
